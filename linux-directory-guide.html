Linux Directory Guide

What lives where in a Linux filesystem, section by section.

Linux follows the Filesystem Hierarchy Standard: every top-level directory has one job. Here is the map; pick a directory in the side panel, such as /etc, to see what lives inside it. Items marked virtual are not stored on disk; the kernel generates them.

/
├── etc/     configuration (text files)
├── usr/     programs, libraries, shared data
├── var/     data that changes: logs, databases, caches
├── home/    user files and per-user settings
├── boot/    kernel and bootloader
├── dev/     devices (virtual)
├── proc/    processes and kernel info (virtual)
├── sys/     devices and drivers (virtual)
├── run/     runtime state since boot (RAM)
├── tmp/     temporary files
├── opt/     self-contained third-party software
└── srv/ mnt/ media/ root/ bin/ sbin/ lib/

Rule of thumb: config in /etc, programs in /usr, changing data in /var, your files in /home. Anything you install by hand goes in /usr/local or /opt so it never clashes with the package manager.

Based on the Filesystem Hierarchy Standard; details vary by distribution.
